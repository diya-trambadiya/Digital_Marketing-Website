# Digital Marketing Website

A modern and responsive digital marketing website developed using HTML, CSS, and JavaScript.

## Features
- Responsive landing page
- Service showcase section
- About us page
- Contact form
- Smooth navigation
- Attractive UI design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository
2. Open `index.html` in any browser

## Purpose
This project is designed to demonstrate a professional digital marketing website interface suitable for agencies and service providers.
